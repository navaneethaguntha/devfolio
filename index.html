Project 2

FinMitra is a web-based financial intelligence platform designed to support small and informal merchants. It provides an alternative credit score, UPI transaction monitoring, fraud alerts, and simple explanations of unusual transactions. The project aims to make financial insights easier to understand and help micro-merchants make safer and more informed financial decisions.
